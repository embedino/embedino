## Criterion 5: AI System Prompt & Hardware Context Leakage Audit — **PASS (Rating: 10 / 10)**

The audit report delivers an outstanding, root-cause investigation into the prompt leakage issue that prompted the user's follow-up requests:

### 1. Defect Topology:
- **Visibility Leakage:** In external provider clients (ChatGPT Desktop App, Codex, Cursor, Grok, OpenCode), the chat thread was titled `[EMBEDINO HARDWARE CONTEXT]` and the entire 50+ line hardware instructions block rendered visibly inside the user's chat bubble.
- **Redundancy / Token Bloat:** The hardware prompt was prepended to every single user turn, duplicating hundreds of lines in thread history.

### 2. Root Cause:
- Naive string concatenation in `CodexAdapter.ts:1820`, `CursorAdapter.ts:970`, `GrokAdapter.ts:959`, and `OpenCodeAdapter.ts:1446`:
  `finalInput = input.input ? hardwarePrompt + "\n\n" + input.input : hardwarePrompt`
- This serialized the hardware instructions into the wire protocol as a `user` role message.

### 3. Upstream Pattern Restored:
- Upstream `pingdotgg/t3code` keeps system instructions hidden via `developer_instructions` in Codex and session configuration in other providers, keeping `sendTurn` strictly pure user text.
- The report provides **complete, line-by-line production diffs** for `CodexDeveloperInstructions.ts`, `CodexSessionRuntime.ts`, `CodexAdapter.ts`, `CursorAdapter.ts`, `GrokAdapter.ts`, and `OpenCodeAdapter.ts`.
